# time-calculator

Простой веб-калькулятор для расчёта времени забега по временным меткам видео.

Калькулятор позволяет указать начало и конец забега (Frame Rate необходимо указывать в ручную!).
После этого он автоматически рассчитывает продолжительность забега и формирует готовый **Mod Note** для копирования.
## https://paklomak.github.io/time-calculator/
