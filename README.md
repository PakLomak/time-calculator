# time-calculator

Калькулятор времени забега.

## Возможности

- Начало забега
- Конец забега
- FPS
- Автоматический расчёт времени
- Готовый Mod Note
- Копирование Mod Note
- История последних 10 результатов
- История сохраняется в браузере через `localStorage`
- Нажатие на результат в истории загружает его обратно
- Отдельная кнопка удаления результата
- Очистка всей истории

История хранится локально в браузере и не отправляется никуда.
